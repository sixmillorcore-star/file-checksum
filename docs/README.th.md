# File Checksum

โปรแกรม Windows สำหรับคำนวณค่า SHA-256 ของไฟล์และเทียบกับค่าที่มีอยู่ เลือกไฟล์หรือลากมาวางในหน้าต่าง แล้วคัดลอกค่าแฮชหรือบันทึกเป็นไฟล์ `.sha256` ได้

[ดาวน์โหลดสำหรับ Windows](https://github.com/sixmillorcore-star/file-checksum/releases/latest) · [English](../README.md)

![หน้าต่างโปรแกรม File Checksum สำหรับ Windows](images/file-checksum.png)

*ภาพพรีวิวจากการเรนเดอร์หน้าต่างโปรแกรม อ่านผลการตรวจและข้อจำกัดได้ใน [VALIDATION.md](../VALIDATION.md)*

## ดาวน์โหลดและเปิดใช้

1. ดาวน์โหลด `FileChecksum-v1.0.0-windows.zip` จากหน้า [Releases](https://github.com/sixmillorcore-star/file-checksum/releases/latest)
2. แตกไฟล์ ZIP แล้วเปิด `FileChecksum.exe`

ใช้กับ Windows 10 หรือ 11 ที่มี .NET Framework 4.8 ไม่ต้องติดตั้งโปรแกรม สมัครบัญชี หรือใส่ API key ตัวโปรแกรมยังไม่ได้ลงลายเซ็นดิจิทัล จึงอาจมีคำเตือนจาก Windows ว่าไม่รู้จักผู้เผยแพร่

## วิธีใช้

- **คำนวณ:** กดปุ่มเลือกไฟล์ หรือลากไฟล์หนึ่งไฟล์มาวางในหน้าต่าง โปรแกรมจะเริ่มคำนวณให้อัตโนมัติ มีแถบความคืบหน้าและปุ่มยกเลิก
- **เปรียบเทียบ:** วางค่า SHA-256 ที่ต้องการเทียบลงในช่อง ค่าแฮชต้องมีตัวอักษรฐานสิบหกครบ 64 ตัว รับได้ทั้งตัวพิมพ์ใหญ่และเล็ก ช่องว่างหัวท้ายจะถูกตัดออก แต่ไม่รับคำนำหน้าหรือช่องว่างที่แทรกอยู่ภายในค่าแฮช
- **คัดลอก:** กดปุ่มคัดลอกเพื่อนำค่าแฮชที่คำนวณได้ไปไว้ในคลิปบอร์ด
- **บันทึก:** เลือกตำแหน่งสำหรับไฟล์ `.sha256` เนื้อหาเป็นค่าแฮช ตามด้วยช่องว่างสองช่องและชื่อไฟล์ต้นฉบับที่ไม่รวมโฟลเดอร์ บันทึกด้วย UTF-8 แบบไม่มี BOM
- **ภาษา:** สลับภาษาไทยและอังกฤษได้ในโปรแกรม การเลือกภาษามีผลเฉพาะครั้งที่เปิดใช้งานอยู่

โปรแกรมทำงานทีละหนึ่งไฟล์ อ่านไฟล์ที่เลือกโดยไม่แก้ไขหรือลบไฟล์ ไม่เชื่อมต่อเครือข่าย และเขียนเฉพาะไฟล์เช็กซัมที่คุณเลือกบันทึก การคัดลอกลงคลิปบอร์ดเกิดขึ้นเมื่อกดปุ่มคัดลอก

ค่าแฮชที่ตรงกันแสดงว่าไฟล์ตรงกับค่าแฮชที่นำมาเทียบ แต่ไม่ได้ยืนยันผู้สร้างไฟล์หรือความปลอดภัยในการเปิดใช้ ควรนำค่าแฮชอ้างอิงมาจากแหล่งที่เชื่อถือได้

## สร้างโปรแกรมจากซอร์สโค้ด

ใช้ Windows ที่มี Windows PowerShell และ .NET Framework 4.8:

```powershell
.\Build.ps1
.\tests\Run-Tests.ps1
.\tests\Run-UiTests.ps1
.\Package.ps1
```

สคริปต์ใช้คอมไพเลอร์ C# ที่มากับ Windows .NET Framework และสร้าง `build/FileChecksum.exe` ส่วนการแพ็กจะได้ `release/FileChecksum-v1.0.0-windows.zip` และ `release/SHA256SUMS.txt`

ดูผลการตรวจใน [VALIDATION.md](../VALIDATION.md) และรายการเปลี่ยนแปลงใน [CHANGELOG.md](../CHANGELOG.md)
