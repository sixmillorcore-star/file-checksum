# Changelog

## 1.0.0 — 2026-10-22

- Calculate a single file's SHA-256 checksum by browsing or dragging and dropping.
- Show progress and allow cancellation while reading a file.
- Compare against an expected SHA-256 hash, copy the result, or save a `.sha256` file.
- Switch between English and Thai for the current session.
- Provide a portable Windows executable, source code, and build scripts under the MIT license.
